# Contributing to test-for-agents

## 1. Setup

Clone the repository and install dependencies:

```bash
git clone https://github.com/<your-username>/test-for-agents.git
cd test-for-agents
npm install
```

## 2. Running Tests

Run the test suite:

```bash
npm test
```

## 3. Submitting Pull Requests

Create a feature branch with a descriptive name:

```bash
git checkout -b feature/your-feature-name
# or
git checkout -b fix/issue-description
```

Push your branch and open a pull request. Use this template:

```
## Description
Brief description of your changes

## Related Issue
Fixes # (issue number)

## Testing
Describe testing performed
```
